# BYKINEKS website work

For font product pages, read `docs/font-page-benchmark.md` and the target entry in `docs/font-profiles.md` before planning or editing. A request such as “beresin Caelia” means apply the benchmark to Caelia's verified capabilities, not copy Bia's page.

Communicate in informal Indonesian. Keep the minimal, editorial, museum-like, glyph-first direction and restrained palette. Preserve existing functionality and use actual font assets. Do not invent specifications, add Free Trial or Specimen PDF functionality, or change unrelated pages/global styles without a task reason. Existing download links may be preserved.

Use a dedicated development branch. Merge and production deployment need explicit user authorization for the current change. Completing an earlier font does not authorize publishing the next one. The user's narrower section scope and corrections override the general benchmark.
