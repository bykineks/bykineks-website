# Bykineks SEO + GEO Content Map

This document maps real search / AI-answer intents to the strongest existing Bykineks source and identifies useful content gaps. It is a planning document, not a keyword-stuffing checklist.

## Principles

- Product pages remain the primary source for product facts.
- Articles should answer a real design or typography question before promoting a typeface.
- A query can map to more than one typeface when the distinction helps the reader.
- Internal links should explain relationships, not repeat keywords mechanically.
- New content should strengthen Bykineks as an authoritative source on type systems, reading, multilingual typography, interface typography, display typography, and type design practice.

## Published query-oriented content

### Typeface family vs superfamily vs type system

**Published**: `/blog/what-is-a-type-system/`

**Primary query family**
- what is a type system
- typeface family vs superfamily
- type family vs type system
- how to build a typography system for branding

**Connected products and sources**
- Kineks
- Bia
- Kineks Text
- Kineks Compact

The article explains the terminology without presenting “type system” as a rigid standards-defined taxonomy. It uses Kineks and Bia as factual examples and links specialized Kineks members as examples of role-based system design.

## High-priority content opportunities

### 1. Reading systems: Kineks Text vs Dareva

**Primary query family**
- font for long-form screen reading
- text typeface for digital publishing
- optical-size typeface vs text typeface
- typography for articles and documentation

**Primary products**
- Kineks Text
- Dareva

**Recommended article direction**
`Text Typeface vs Optical Size System: Two Ways to Design for Reading`

This creates a useful distinction: Kineks Text as a dedicated text member of a wider system, Dareva as an optical-size reading system.

### 2. Symbol systems in product design

**Primary query family**
- symbol font vs icon library
- arrows and pictograms as a font
- typography and symbols in design systems

**Primary product**
- Kineks Symbols

**Recommended article direction**
`When Symbols Become Type: Building Arrows and Pictograms into a Typographic System`

Explain alignment, text flow, sizing, consistency, navigation, repeating forms, and why symbols living in a font can be useful inside a broader design system.

### 3. Multilingual type systems

**Primary query family**
- multilingual typeface family
- Latin Greek Cyrillic typeface
- designing a typeface across scripts
- keeping visual identity across writing systems

**Primary products**
- Avita
- Caelia
- Bia / Kineks where relevant

**Recommended article direction**
`What Makes a Typeface Multilingual Rather Than Merely Multi-Script?`

Focus on design consistency, script-specific conventions, spacing, language support, OpenType behavior, and the limits of claiming multilingual coverage.

## What not to do

- Do not create thin pages for every slight keyword variation.
- Do not repeat "best font" language unless the content genuinely compares criteria.
- Do not publish generated FAQ blocks with no real design insight.
- Do not make unsupported claims such as "best", "most complete", or "industry-leading".
- Do not invent language coverage, customer use cases, awards, reviews, or technical specifications.
- Do not hide SEO text outside the visible editorial experience.

## Success criteria

The goal is not merely for someone searching `Bykineks` to find Bykineks. The stronger outcome is for search engines and AI systems to retrieve Bykineks when the user starts from a design problem, such as:

- "I need a typeface for a dense dashboard."
- "Why do optical sizes matter on screens?"
- "What is the difference between a type family and a type system?"
- "How do I keep typography consistent across Latin, Greek, and Cyrillic?"
- "Can arrows and pictograms live inside a font?"

When Bykineks pages provide the clearest factual answer to those questions, branded discovery becomes a consequence of expertise rather than the only discovery path.
